# GrowthPilot｜AI 增长实验策划助手

> 把一个模糊的增长问题，逐步转化为可以执行、验证和复盘的实验方案。

## 在线体验

**Demo：** https://bellaliii.github.io/clarify-ai/

无需登录或配置 API Key，电脑和手机浏览器均可直接使用。

## 项目简介

在增长运营工作中，业务方通常能够描述现象，例如“新用户注册后没有继续使用”或“活动有流量但付费转化较低”，但不一定能立刻明确：

- 应该优先解决拉新、激活、留存、召回还是变现问题；
- 还缺少哪些关键信息；
- 可以设计哪些低成本实验；
- 应该如何设置指标、对照组和优先级。

GrowthPilot 面向产品、用户运营和增长团队。用户只需输入业务问题，系统就会判断可能的增长目标，并根据该目标继续追问用户阶段、行为障碍、可用渠道、资源限制和核心指标，最终生成三套差异化实验方案。

## 使用流程

1. **描述问题**：用自然语言输入产品现状、目标和限制。
2. **确认目标**：系统推荐拉新、激活、留存、召回或变现方向，用户可以修改。
3. **补充信息**：后续问题、选项、示例和指标会随目标分支切换。
4. **生成方案**：获得三套实验路线、实验步骤、A/B 测试设计和指标建议。
5. **比较优先级**：通过 ICE 分数判断更适合先验证哪一套方案。
6. **保存结果**：支持复制、下载和保留历史记录。

## 示例

可以将下面这段文字直接复制到网页中体验：

> 我们有一款面向职场新人的播客 App，希望提高新用户留存。目前很多用户注册后只播放过一次内容，第二天没有再次打开 App。团队可以使用站内推荐、Push 通知和新手任务，但开发资源和激励预算都比较有限。

系统会先推荐“留存”目标，并继续了解用户流失阶段、可能的行为障碍、可使用的触达渠道、资源投入和目标指标。在信息补充完成后，系统会输出：

- **低成本验证方案**：优先验证内容推荐和首日体验是否影响次日回访；
- **激励驱动方案**：用轻量任务或阶段奖励培养连续使用行为；
- **个性化触达方案**：根据首次收听内容进行差异化推荐和召回。

每套方案均包含实验假设、目标人群、执行步骤、实验组与对照组、核心指标、护栏指标、风险提醒和下一步行动。

## 核心功能

- 根据问题描述推荐增长目标；
- 按目标动态切换问题、选项、示例和指标；
- 支持多选渠道和资源条件；
- 生成三种不同侧重点的实验方案；
- 自动整理实验假设、执行步骤和 A/B 测试设计；
- 从 Impact、Confidence、Ease 三个维度计算优先级；
- 生成下一步执行清单；
- 支持复制、下载和本地历史记录；
- 响应式页面，适配电脑和手机。

## 动态逻辑说明

当前版本不是把所有用户带入同一套固定问卷。系统会先识别问题中的目标与关键词，再进入对应分支：

| 增长目标 | 重点追问 | 常用指标示例 |
| --- | --- | --- |
| 拉新 | 来源渠道、目标人群、获客成本 | 新增用户数、CAC、注册转化率 |
| 激活 | 首次关键行为、体验障碍 | 激活率、关键行为完成率 |
| 留存 | 流失阶段、回访动机、触达渠道 | 次日/7 日留存率、回访率 |
| 召回 | 沉默周期、召回触点、回归权益 | 召回率、回归后留存率 |
| 变现 | 付费场景、价格障碍、用户价值 | 付费率、ARPU、收入 |

在同一个目标分支中，用户选择的渠道、资源和限制也会继续影响最终方案内容。因此输出并非随机生成，而是根据输入条件进行可解释的组合。

## ICE 优先级

系统从三个维度为每套方案评分：

- **Impact**：对核心指标的潜在影响；
- **Confidence**：当前信息和实验依据的充分程度；
- **Ease**：实施难度、资源和时间成本。

当前计算方式：

```text
ICE = (Impact + Confidence + Ease) / 3 × 10
```

ICE 用于方案初筛，不代表真实业务收益。实际落地时仍需结合历史数据、团队经验和实验结果校准。

## AI 在项目中的作用

AI 参与了需求拆解、产品流程设计、增长场景梳理、前端代码生成、交互文案优化和测试验证。

网页运行阶段采用本地动态规则引擎，不会在公开前端存放 API Key。这样设计有三个原因：

1. 用户无需注册或付费即可稳定体验完整流程；
2. 用户输入默认只保存在当前浏览器中；
3. 避免公开网页暴露 API Key 带来的安全和费用风险。

因此，当前版本体现的是“AI 辅助完成产品设计与开发 + 可解释的智能工作流”，而不是声称每次输出都由在线大模型实时生成。未来可通过后端代理安全接入大模型，使追问和方案表达更加开放。

## 当前边界

- 动态问题基于增长阶段和规则分支，不是大模型实时生成；
- ICE 是方案筛选参考，不能替代真实数据分析；
- 生成结果用于形成实验初稿，正式上线前仍需进行业务、合规和技术评审。
